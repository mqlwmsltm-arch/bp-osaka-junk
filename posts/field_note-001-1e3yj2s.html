구체적 내용:
- Cloudflare cache reserve: 엣지 로케이션에서 오리진으로부터 콘텐츠를 캐싱하는 기능. 무효화 지연이 발생하면 사용자에게 오래된 콘텐츠가 제공될 수 있음.
- Lightsail CPU 크레딧: Lightsail 인스턴스에서 CPU 크레딧이 소진되면 성능 제한. 이것과 cache reserve 지연이 어떤 연관이 있을까? DNS 장애로 인해 오리진과의 통신이 느려져 캐시 무효화가 지연될 수도 있고, Lightsail 인스턴스가 CPU 크레딧을 소모하는 상황과 연결?
